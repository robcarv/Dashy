# Dashy

Personal dashboard configuration for Dashy.

This repository contains the configuration file used in my homelab Dashy instance.

**Live dashboard:**
- Pi501: http://192.168.68.117:8200
- Pi4: http://192.168.68.102:8200

**Full configuration project:** [dashy-homelab](https://github.com/robcarv/dashy-homelab)

## About

Dashy is a self-hostable dashboard for monitoring services, apps, and infrastructure.
This repo mirrors the `conf.yml` used across my Raspberry Pi cluster.

See [dashy-homelab](https://github.com/robcarv/dashy-homelab) for the full infrastructure documentation.
